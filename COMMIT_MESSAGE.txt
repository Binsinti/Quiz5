Fix critical bugs in Quiz5 exam system

ISSUES RESOLVED:

1. LOGOUT REDIRECT BUG
   - Problem: Users redirected to Django admin login (/admin/login/) instead of custom signin page after clicking Sign Out
   - Fix: Added url = '/auth/signin/' property to CustomLogoutView class in authentication/views.py
   - Result: Logout now properly redirects to custom signin page

2. EXAM UNAVAILABLE BUG
   - Problem: Students couldn't access exams showing "Unavailable - This exam is currently not available" even during valid time periods
   - Fix: Added missing context['exam_status'] = exam.get_status_for_student(student) in StudentExamView.get_context_data()
   - Result: Exams now show correct availability status (Available, Coming Soon, Expired, etc.)

3. EXAM CREATION ACCESS DENIED
   - Problem: Teachers getting "Access denied. Teachers only." when trying to create exams due to missing permission validation
   - Fix: Added test_func() method returning self.request.user.is_teacher to ExamCreateView class
   - Result: Teachers can access /exam/create/, students properly blocked with access denied message

4. STUDENT PROFILE STATISTICS MISSING
   - Problem: Student profile page showed empty statistics cards with no data for Total Exams, Pass Rate, or grade distribution
   - Fix: Added total_exams_taken calculation and comprehensive statistics logic in StudentProfileView.get_context_data()
   - Result: Profile displays complete exam statistics including total exams, passed/failed counts, pass rate, and grade distribution

5. TEACHER PROFILE CRASH
   - Problem: UnboundLocalError for 'allocated_time_minutes' when teacher profile loads with multiple exams having different submission states
   - Fix: Moved allocated_time_minutes = exam.duration_minutes definition outside conditional block in TeacherProfileView
   - Result: Teacher profile works correctly for all exam scenarios (with/without submissions)

6. USER MODEL IMPORT ERRORS
   - Problem: AttributeError "Manager isn't available; auth.User has been swapped for accounts.CustomUser" in forms and views
   - Fix: Standardized imports to use "from accounts.models import CustomUser as User" consistently across all files
   - Result: No more Django user model conflicts, consistent CustomUser usage throughout application

7. STACKING NOTIFICATION PROMPTS
   - Problem: Login/logout messages were stacking on top of each other due to duplicate message displays
   - Fix: Implemented centralized message system in base.html with fixed positioning and removed duplicate displays
   - Result: Clean, non-overlapping notifications in top-right corner with auto-dismiss functionality

8. DEBUG_TIMEZONE_VIEW IMPORT ERROR
   - Problem: debug_timezone_view was being imported in exam/urls.py but didn't exist in exam/views.py
   - Fix: Removed debug_timezone_view from import list and cleaned up other unused imports in exam/views.py
   - Result: No more import errors, cleaner codebase with only necessary imports

FILES CHANGED:
- authentication/views.py (CustomLogoutView, StudentProfileView, TeacherProfileView)
- exam/views.py (ExamCreateView, StudentExamView, import cleanup)
- exam/forms.py (User model import standardization)
- templates/base.html (global message system implementation)
- authentication/templates/authentication/signin.html (removed duplicate message display)
